# Отчёт о проверках VidHarbor

## S01

Проверки каркаса выполнены 10–11 ноября 2026 года. Результаты относятся к минимальному VidHarbor и отдельному стенду T103.

| Проверка | Результат |
|---|---|
| T101, T102, T104 | Linux-контейнер запустился. Compose поднял каркас с пустыми томами, Chrome отрисовал страницу. При остановке PostgreSQL и RabbitMQ `live` оставался `200`, `ready` возвращал `503` и восстанавливался до `200`. Проверены шаблон настроек и исключение секретов из Git. [Протокол запуска](protocols/s01-runtime.md). |
| T103 | На отдельном стенде прошли повторная выдача при падении обработчика, блокировка общей папки при живом FFmpeg, потеря heartbeat и таймаут подтверждения. [Протокол RabbitMQ](protocols/s01-rabbitmq.md). |
| GitHub Actions | Прогон для `955c854` в PR №2 прошёл. GitHub собрал ветку вместе с `main`, поднял Compose с чистыми томами, отрисовал страницу в Chrome и проверил отключение и восстановление обеих зависимостей. [Прогон CI](https://github.com/ruiskhakov2017-sys/vidharbor/actions/runs/43032163988). |

По S01 подтверждены P01–P05 в пределах каркаса. Полная демонстрация F13, проверки телеметрии и восстановления, а также полный набор CI T703 относятся к следующим этапам.

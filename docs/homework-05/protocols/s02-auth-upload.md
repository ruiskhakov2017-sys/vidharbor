## T203 · Оригинал и единственное задание

Оба файла из Chrome сохранились со статусом загрузки `COMPLETE`. Для каждого SHA-256 файла на томе совпал с SHA-256 исходника. PostgreSQL показал одну запись `Job` и одну запись `Outbox` с `sent_at IS NULL` на видео. Прямой HTTP-запрос оригинала вернул `404`.

## Команды повторения

На тестовом проекте задайте `COMPOSE_PROJECT_NAME`, `VIDHARBOR_PORT`, `VIDHARBOR_SECRETS_DIR`, `VIDHARBOR_MAX_UPLOAD_BYTES=8388608` и при необходимости `VIDHARBOR_CHROME`. Для Playwright передайте два малых тестовых видео. Для проверки промежуточного прогресса первый образец должен быть достаточно крупным, в прогоне использовано около 2 МиБ.

```powershell
docker compose --env-file .env.example up --build -d --wait --wait-timeout 180
python scripts/smoke_s02.py test-results/s02/author-a.mp4 test-results/s02/author-b.webm
docker compose --env-file .env.example exec -T upload python manage.py test vidharbor.test_uploads --noinput -v 2
python scripts/smoke_s01.py
```

В повторном прогоне `smoke_s02.py` создаёт новые тестовые аккаунты. Для измерений промежуточного `.part`, памяти и границ использован локальный сценарий `test-results/s02/http_checks.py`.
